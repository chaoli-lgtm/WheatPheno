# Study evaluation summaries

These tables report the study's plot-grouped cross-validation results:

- `model_comparison.csv`: aggregate algorithm comparisons.
- `repetition_metrics.csv`: metrics for each validation repetition.
- `subgroup_metrics.csv`: performance by trial, cultivar, treatment and growth stage.

Metrics come from the original study evaluation, not the limited public examples or synthetic fixtures. Public examples are supplied for execution checks.
